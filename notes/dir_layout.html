duni compiler · notes/ · intermediate representation

DIR is three flat arrays.
Nothing else.

Every instruction's inline data is exactly 8 bytes — anything bigger spills to extra. Names are interned into string_bytes. No pointers anywhere: a program is three slices, a copy is a memcpy, and analysis passes share it immutably. Hover anything to trace its cross-references. Step through the emission timeline to watch AstGen build it.

Ref, the one u32 vocabulary: values below static_len = 7 are InternPool constants; everything else names an instruction. A param type and a callee live in identical slots with zero tag bits.

8-byte Data, spill everything else

ExternFunc and Call don't fit in the union → pl_node keeps only {src_node, payload_index}; header + trailing refs go to extra, contiguous. This is why scratch exists — lowering an argument writes other payloads into extra in between.

Names are handles, matches are integer compares

extern_func and decl_val both say “print” as the integer 1. Sema's name→function resolution in the next commit is a u32 compare against a table — no string ever gets compared twice.

Emission order is layout; the module points backward

extra interleaves payloads by when each instruction lowered. setModule runs last, so the module's payload sits at the end describing instructions before it — that's the whole reason the slot at %0 is reserved early and filled late.

Bodies are index lists, decls precede statements

A body holds instruction indexes, executed in order. Decls lower before statements so Sema — which walks in order — meets every extern_func before the first call that names it.

All source positions are relative

src_node is an offset from the decl node, src_tok from the decl's first token. Instructions are relocatable between contexts; the arrays are position-independent — the property incremental compilation would need.

No pointers, ever

The program is three slices. deinit is three frees, a copy is a memcpy, and concurrent analyses share it immutably — a promise the doc comment at the top of Dir.zig makes explicitly.
